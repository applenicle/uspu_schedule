# Расписание УрГПУ — мобильный веб-сервис и Telegram Mini App

**Репозиторий:** `https://github.com/applenicle/uspu_schedule.git`

## Что реализовано

- Next.js App Router, структура **Feature-Sliced Design** в `src/`.
- Одна настоящая React-страница для мобильного и десктопного сайта — **отдельного HTML-превью нет**.
- Две темы, фокус/контрастные состояния, HTML `lang="ru"`, смысловые заголовки, переход к основному содержимому.
- Цветные карточки по типу пары, время двумя строками **без тире**, выбор даты с подписью месяца.
- Поиск групп без учёта дефиса, регистра и пробелов; преподаватели и аудитории; сохранение избранного в localStorage.
- Параллельные занятия 1-й/2-й подгруппы в одном временном слоте, кабинет справа; длинные ФИО показываются в карточке преподавателя полностью.
- Backend API на Next.js + PostgreSQL/Neon и самостоятельный Python-сборщик для российского сервера.

> Важно: **без БД и сборщика продакшен-сайт не показывает реальное расписание.** Для просмотра функционала используйте `/?demo=1`, где данные вымышленные и помечены как демонстрационные. Демоверсия нужна только для оценки UI.

## Локальный запуск

Нужен Node.js 22 (минимум 20.9) и npm. В корне:

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000/?demo=1` для просмотра мобильной веб-версии. Скриншоты нужно делать **с этой же Next.js-страницы**, а не с отдельного HTML-файла.

Проверки логики:

```bash
npm test
python3 -m unittest discover -s worker -p 'test_*.py'
```

## Настоящее расписание и Neon

1. Создайте в Vercel проект из GitHub-репозитория и подключите PostgreSQL через Neon.
2. В Neon SQL Editor выполните `sql/schema.sql`.
3. В Vercel Project Settings → Environment Variables задайте `DATABASE_URL`, `WORKER_TOKEN`, `RATE_LIMIT_SALT` (каждый секрет независимый; `openssl rand -hex 32`).
4. Деплойте Vercel и откройте `/` (без `?demo=1`). Пока каталог не синхронизирован, поиск покажет ошибку или пустой список — это ожидаемо.
5. На российском VPS, где **проверен доступ к `uspu.ru`**, создайте отдельную директорию только для `worker/`, без изменения существующих сервисов. В виртуальном окружении установите `worker/requirements.txt`. Настройте `worker/.env` по шаблону: `API_URL=https://ВАШ-ДОМЕН`, `WORKER_TOKEN=<тот же секрет, что в Vercel>`.
6. Выполните однократный тест: `python3 worker/collector.py --once`, проверьте логи и каталоги. Затем запланируйте ограниченную по частоте синхронизацию через systemd по примеру `worker/uspu-collector.service.example`.
7. Переход из группы в преподавателя использует поиск по каталогу; расписания загружаются по запросу пользователя и позже синхронизируются сборщиком.

**Не опрашивайте одновременно все 937 групп**: сборщик работает только с востребованными расписаниями, выполняет ограниченные пачки запросов и паузы между ними. Соблюдайте правила использования источника и не перегружайте сайт.

Фотографии, email и личные телефоны преподавателей **не подставляются**, так как найденные endpoints расписания этих данных не предоставляют. Поиск аудиторий опирается только на уже загруженные занятия и **не является полной картой занятости** университета.

## GitHub — первая отправка

Команды для терминала WSL, из распакованной директории `uspu_schedule`:

```bash
cd ~/uspu_schedule
# если вы скачали архив, сначала распакуйте его сюда
git init -b main
git remote add origin https://github.com/applenicle/uspu_schedule.git
git add .
git status --short
# убедитесь, что .env, node_modules и секретов в списке нет
git commit -m "feat: initial USPU schedule app with FSD architecture"
git push -u origin main
```

Если репозиторий создан с README или LICENSE, перед первым push потребуется объединить историю, например через `git pull origin main --allow-unrelated-histories` и разрешить возможные конфликты; предпочтительно создать GitHub-репозиторий **пустым**. Если `remote origin already exists`, используйте `git remote set-url origin https://github.com/applenicle/uspu_schedule.git`.

Для следующих изменений:

```bash
git add .
git commit -m "fix: refine mobile schedule UI"
git push
```

Для приватного GitHub можно использовать SSH remote `git@github.com:applenicle/uspu_schedule.git`, если SSH-ключ уже настроен.

## Структура FSD

```
src/
  app/         # Next.js App Router, глобальные стили и API endpoints
  fsd/pages/   # экран расписания (Next.js резервирует src/pages под другой роутер)
  widgets/     # шапка, список занятий, карточка преподавателя
  features/    # поиск, выбор дня, избранное, темы
  entities/    # занятие, каталог, расписание, модели и API
  shared/      # даты, форматирование, демоданные, утилиты
worker/        # Python + BeautifulSoup, работающий на доступном российском VPS
sql/           # структура PostgreSQL
```

## Известные ограничения

- Веб-сборку `next build` требуется выполнить после установки npm на машине с доступом к registry. В среде генерации npm registry недоступен.
- Полный аудит клавиатурной навигации, экранных дикторов, 200% zoom и независимые проверки WCAG AA — **ещё не выполнены**.
- Доступность домена Vercel в РФ без VPN и с зарубежным VPN необходимо измерить до публичного запуска; Vercel сам по себе этого не гарантирует.
- Для Telegram Mini App нужен рабочий публичный HTTPS-адрес и привязка веб-приложения к боту.
