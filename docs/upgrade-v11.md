# USPU Schedule v11 — Telegram Bot API Rich Messages + Premium меню

## Что изменено

- Расписание в Telegram отправляется **реально через `sendRichMessage`** с `rich_message: {html: ...}`, а не через старое `sendMessage` с `parse_mode=HTML`.
- В сообщениях есть заголовки `<h2>/<h3>`, разделители `<hr/>`, списки `<ul>/<li>`, заметки `<footer>`, проверенные premium-эмодзи `<tg-emoji>`.
- В inline-клавиатурах короткие кнопки в стиле MuteVPN: `Расписание группы`, `Преподаватели`, `Помощь`, `Открыть приложение`. Стандартная навигация по дням, `Сегодня`, `Завтра`, `Неделя`, `Меню`.
- У всех кнопок с иконками `icon_custom_emoji_id`; обычные эмодзи в текстах кнопок не дублируются. Использован `tgiosicons` — тот же набор iOS-иконок, что применялся в проекте MuteVPN. Проверенные ID: https://emoji.wivvi.net/llms.txt.
- По кнопкам «Группа» и «Преподаватель» бот запрашивает ввод через Telegram ForceReply. Никаких аккаунтов, таблиц пользователей или хранения Telegram ID.
- Подгруппы остаются отдельными элементами списка со своими преподавателями и кабинетами; длинные ФИО не обрезаются.
- Предпросмотр `/api/telegram/message` теперь отдаёт объект `rich_message`, не отправляя сообщение.
- При отсутствии права использовать Premium-эмодзи бот повторяет запрос **через тот же Rich Messages API**, но без custom emoji; это не переход на обычный текст.

## Проверка после Vercel Ready

Webhook уже настроен: повторно регистрировать не нужно. В Telegram открой бота и нажми `/start`, затем `Расписание группы` и введи `ДГ-304`, либо отправь `/week ДГ-304`. Нажми `Преподаватели` и введи реальное ФИО из каталога.

В Vercel Logs проверять путь `/api/telegram/webhook`. При отсутствии прав на Premium-эмодзи будет обычный fallback без custom icons; чтобы увидеть их, владелец бота должен иметь Telegram Premium или подходящее право, как указано в Bot API.

## Ограничения

Это протестированный локально патч исходников, но **не доказанная живая отправка через Telegram API** — для неё нужны реальные токены и готовый Production-деплой. Некоторые старые Telegram-клиенты могут отображать Rich Message блоки иначе.

**Не затрагиваются:** Neon schema, московский worker, Vercel секреты, webhook URL, сайт и настройки VPN.
