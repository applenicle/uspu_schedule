# USPU Schedule v15 — навигация и каталоги

- Нижняя мобильная навигация: Группы / Преподаватели / Аудитории. Стиль «Liquid Glass» реализован как мягкая полупрозрачная поверхность с размытием, но текст и активное состояние сохраняют контраст, при отключённой прозрачности используется непрозрачная поверхность.
- На ПК переключатель категорий остаётся сверху; на телефонах верхнее дублирование убрано.
- Кабинет находится под преподавателем **слева**. Длинные подписи переносятся по словам и не сжимаются до букв.
- Номер подгруппы отображается, только когда его передал источник. `0` не превращается в `1`/`2`.
- Преподавателя и группу можно изменить из поиска, не теряя предыдущих сохранённых данных.
- В Telegram: «Выбрать расписание» / «Сменить расписание» вместо неопределённого «Найти».
- Из каталога временно скрываются *недавно успешно синхронизированные* группы/преподаватели, у которых сохранён пустой массив занятий. Отсутствие кэша или ожидание worker никогда не считаются подтверждённой пустотой. Через 12 часов записи снова доступны для проверки, а уже запрошенные расписания могут обновиться раньше через worker. Никаких данных не удаляется.
- Neon и worker не требуют миграций и перезапусков.
