# v20 — понятный вход в бота и подтверждённые подгруппы

## Telegram

- `/start` присылает **одно** короткое сообщение и нижнюю клавиатуру из двух кнопок: **«Выбрать расписание»**, **«Открыть приложение»**.
- Бот больше не присылает повторное сообщение «Быстрый доступ к расписанию» после каждой пары, поиска или переключения даты.
- Студент может сразу написать `дг304` или `Шмакова`. При нескольких совпадениях выбирает ФИО кнопкой.
- После выбора расписания в сообщении доступны inline-кнопки дней и недели; нижняя клавиатура при этом остаётся на месте.

## Подгруппы — почему не появились 1/2 и как добавить правильно

В HTML УрГПУ иногда встречается `<!--Подгруппа: 0-->`. Это не номер первой подгруппы. По названиям преподавателей и порядку элементов нельзя достоверно определить соответствие 1/2.

В новом обновлении добавлена **единая проверяемая карта** соответствий, которую сайт и бот используют одновременно. После подтверждения фактов (например, старостой) запусти в WSL:

```bash
cd ~/uspu_schedule
node scripts/assign-subgroups.mjs \
  --group 'Дг-304' --subject 'Веб-дизайн' \
  --first 'ПОЛНОЕ ФИО ПРЕПОДАВАТЕЛЯ 1-й ПОДГРУППЫ' \
  --second 'ПОЛНОЕ ФИО ПРЕПОДАВАТЕЛЯ 2-й ПОДГРУППЫ' \
  --confirmed

git add src/shared/lib/verified-subgroup-assignments.mjs
git commit -m 'data: confirm subgroup mapping'
git push origin main
```

Нельзя подставлять примерные значения — это расписание для студентов. Если распределение меняется по датам, можно добавить `--date 2026-11-10`, а также `--time '10:15 - 11:45'`.

При наличии реального номера в HTML он имеет приоритет над ручным сопоставлением. Если номер отсутствует и не подтверждён — обе записи показываются без ложной цифры.
