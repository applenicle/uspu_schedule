# USPU Schedule v14 — исправления расписания и навигации

Релиз предполагает, что локальный `main` уже содержит v13, и не затрагивает базу данных Neon или московский worker.

## Веб

- Пустой экран больше не показывает сочетание «Выберите расписание / Сменить». Кнопка смены появляется только после выбора группы, преподавателя или аудитории.
- В окне поиска можно переключить тип расписания **Группы / Преподаватели / Аудитории** без закрытия окна.
- Преподаватель и аудитория располагаются на отдельных строках; аудитория привязывается к **правому краю** каждой карточки и каждой записи с преподавателем.
- Время начала выделено сильнее окончания; дни календаря имеют читаемую типографическую иерархию.
- Светлая и тёмная темы смягчены. В карточках с несколькими записями удалён длинный служебный текст «Параллельные занятия · номер подгруппы не указан».

## Telegram

- `sendRichMessage`: каждый временной интервал отображается отдельно, без объединения нескольких пар по одному предмету.
- Дни недели выделены в заголовки `<h2><mark>...</mark></h2>`; записи оформлены блоками `<blockquote>` с отделённым временем, предметом, преподавателями и аудиториями.
- Если номера подгрупп явно присутствуют в исходном HTML, используются исходные `1`/`2`. В противном случае никакие номера не выдумываются, обе записи преподавателей остаются видны.
- Если найдено несколько преподавателей по фамилии, бот отправляет **кнопки с ФИО**. Нажатие открывает расписание выбранного ID без ручного набора `/teacher`.

## Особенности данных

УрГПУ использует HTML-комментарии вида `<!--Подгруппа: 0<br>-->` для некоторых записей. Здесь `0` не означает первую или вторую подгруппу: worker правильно сохраняет пустой `subgroup`. Реальный номер нельзя восстановить только из таких данных. Назначение номера по порядку преподавателей было бы ошибкой.

## Установка

Скачать `apply_uspu_v14.sh` и запустить в WSL:

```bash
bash /mnt/c/Users/Iurii/Downloads/apply_uspu_v14.sh
```

Скрипт проверит чистоту Git-дерева и ожидаемую v13-структуру, применит патч, выполнит тесты, создаст коммит и отправит его в GitHub. При ошибке после применения файлы остаются для диагностики: **скрипт нельзя применять повторно наугад**.

После успешного push проверить статус Vercel Production. Webhook регистрировать повторно не требуется, так как URL обработчика не меняется. Для проверки бота: `/week Дг-304`, поиск `Шмакова` и выбор преподавателя кнопкой.
