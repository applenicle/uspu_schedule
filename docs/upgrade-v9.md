# Обновление USPU Schedule — v9

Эта версия изменяет веб-приложение и добавляет read-only форматтер Telegram. На VPS worker менять или перезапускать **не нужно**.

Что изменено:
- Тема по умолчанию `auto`: обычный браузер следует системной теме, Telegram Mini App — теме Telegram. Через верхнее меню можно выбрать ручной режим и затем вернуться к `Как на устройстве`.
- Избранное остаётся локальным для конкретного браузера. Категории группы / преподаватели / аудитории не смешиваются. Авторизация через Telegram не требуется.
- Мобильный поиск: полноэкранное окно; поле ввода закреплено наверху и не получает автоматический фокус, чтобы клавиатура не скрывала его при открытии.
- Поиск преподавателя из занятия принимает сокращённые ФИО, но не подставляет случайного преподавателя при совпадении фамилии и инициалов; в таком случае предлагает выбрать вручную.
- Ожидающее расписание автоматически проверяется до завершения загрузки работником.
- Длинные аудитории сокращены до номера в карточке и доступны полностью через title / aria-label; номер выравнивается справа.
- Реальные подгруппы помечены своим номером, а параллельные занятия без указанной в источнике подгруппы не получают вымышленный номер.
- Текст про отсутствие фотографий/контактов удалён из карточки преподавателя.
- Дублирующий переключатель темы в нижней навигации удалён.
- `/api/telegram/message?kind=group&id=Дг-304&date=2026-11-09` выдаёт подготовленный HTML для Telegram Bot API, но **сам не отправляет сообщения**. Бота требуется подключить отдельно.

Применение:

```bash
cd ~/uspu_schedule
git status --short
git pull --ff-only origin main
git apply --check /mnt/c/Users/Iurii/Downloads/uspu_schedule_v9.patch
git apply /mnt/c/Users/Iurii/Downloads/uspu_schedule_v9.patch
npm ci || npm install
npm test
npm run build
git add .
git commit -m "fix: responsive schedule, auto theme and Telegram formatting"
git push origin main
```

Если `git apply --check` не прошёл, **не применяйте патч силой**: вероятно, в репозитории другие изменения; можно использовать исходники из ZIP для ручного сравнения.

Проверка после Vercel deploy:
1. Переключить тему ОС: при `auto` интерфейс должен переключиться.
2. Открыть в Telegram и изменить тему Telegram.
3. Открыть поиск на телефоне, вызвать клавиатуру, проверить видимость поля.
4. В избранном группы не должны смешиваться с преподавателями.
5. Нажать на преподавателя из группы: открывается карточка; «Открыть полное расписание» выбирает преподавателя из каталога или предлагает поиск, если имя неоднозначно.
6. При первом посещении нового расписания дождаться его появления без ручного обновления страницы (worker продолжает работать).

Никаких переменных окружения добавлять не нужно. `DATABASE_URL`, `WORKER_TOKEN` и worker/.env не затрагиваются.
