# v18 — параллельные занятия, deep links и удобный ПК

- Подтверждённые `1/2` из УрГПУ показываются как официальные номера подгрупп.
- Если источник отдаёт `0`/пусто, параллельные занятия получают устойчивые для конкретной карточки метки **Вариант А/Б**, без ложного утверждения об официальном распределении. В Telegram добавлено краткое пояснение, в вебе — `title` на метке.
- Для точного 1/2 есть `verifiedSubgroupAssignments` в `src/shared/lib/subgroup-resolution.mjs`; правила должны быть подтверждены университетом.
- Telegram-кнопка «Открыть приложение» передаёт `kind`, `id`, `label` в URL, а веб-версия ставит их выше сохранённого в `localStorage` выбора.
- ПК: адаптивная сетка, переключение «Неделя / День», читаемая горизонтальная строка времени, компактный заголовок и карточки без сжатых колонок.
- Worker, SQL и Neon не изменяются.
